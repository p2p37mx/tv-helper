# مساعد الشاشة

- `tv` ← تطبيق الشاشة (Android TV): واجهة بيها صورك وترتيب تطبيقاتك + يستقبل الأوامر من التلفون
- `phone` ← تطبيق التلفون: ريموت، إضافة صور، ترتيب وإخفاء التطبيقات
